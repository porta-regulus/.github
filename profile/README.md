# Porta Regulus B.V.

We operate [CVD Portal](https://cvdportal.com), a platform that covers every EU Cyber Resilience Act (CRA, Regulation (EU) 2024/2847) obligation in one place.

## Public repositories

- [cvdportal-mcp](https://github.com/porta-regulus/cvdportal-mcp). MCP server and agent skills for CVD Portal.
- [cvd-portal-claude-plugin](https://github.com/porta-regulus/cvd-portal-claude-plugin). Claude Code plugin for CRA gaps, CVD contact files and SBOM upload.
- [pr-risk](https://github.com/porta-regulus/pr-risk). Free, local-first risk register for NIST SP 800-221r1.
