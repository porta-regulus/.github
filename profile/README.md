# Porta Regulus B.V.

We operate [CVD Portal](https://cvdportal.com), a platform that covers every EU Cyber Resilience Act (CRA, Regulation (EU) 2024/2847) obligation in one place.

## Public repositories

- [cvdportal-mcp](https://github.com/porta-regulus/cvdportal-mcp). MCP server and agent skills for CVD Portal.
- [cvd-portal-claude-plugin](https://github.com/porta-regulus/cvd-portal-claude-plugin). Claude Code plugin for CRA gaps, CVD contact files and SBOM upload.
- [pr-risk](https://github.com/porta-regulus/pr-risk). Free, local-first risk register for NIST SP 800-221r1.

## Open data (CC BY 4.0)

- [cra-exposure-study](https://github.com/porta-regulus/cra-exposure-study). How many EU manufacturers publish a security.txt file and a vulnerability disclosure policy.
- [cra-requirements-catalogue](https://github.com/porta-regulus/cra-requirements-catalogue). The 22 essential cybersecurity requirements of CRA Annex I with stable identifiers.
- [cra-nis2-ssdf-crosswalk](https://github.com/porta-regulus/cra-nis2-ssdf-crosswalk). CRA requirements mapped to NIS2 and NIST SSDF.
- [cra-standards-progress](https://github.com/porta-regulus/cra-standards-progress). Status of the ETSI EN 304 vertical standards for the CRA.
